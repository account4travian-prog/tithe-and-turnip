# Tithe and Turnip: a farming game line

A line of farming-game work built with AI coding help: an earlier farming-game archive, a 2D farming sim built in Godot by a multi-agent team, and a 2.5D presentation spike.

**My role:** game design and direction, and the acceptance calls. The code and assets were produced by agent teams (Claude, Codex, DeepSeek) working in the project folders from my specifications.

## What the record shows
- Three model families worked the same project in separate workspaces with their own written briefs, coordinated through one development-state document so a new session resumed from the project rather than from a chat history.
- The 2.5D spike carries the line's evaluation artifact: a harness optimizer, with bot-report and bug-report folders. No tuning result is claimed.
- An earlier build is kept as a GPU rental archive dated 2026-08-09.
