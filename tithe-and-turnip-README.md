# Tithe and Turnip: a farming game, and the attempts around it

One entry for a whole line of work: a farming game built with AI coding help, plus the earlier versions and tools it grew out of. I'd rather show the line honestly, including the dead ends, than present the latest build as if it appeared from nowhere.

My role: game design and acceptance. The code was written by AI coding agents from my specifications; I playtest, rule on what works, and decide what gets kept.

## What's in the line
- **The game itself**, a farming sim: crops, seasons, a village economy with a tithe mechanic that gives the game its name.
- **The 2D version and a 2.5D spike**, the same idea tried in two forms; the spike answered its question (the look worked, the workload didn't) and was stopped, which is what spikes are for.
- **A harness optimizer**, a tool that runs the game headlessly and tunes parameters against playability measures instead of my gut feeling alone.
- **An archived cloud run**, an earlier build preserved from a GPU rental experiment, kept so the state of the work at that point isn't lost.

## Honest state
This is a hobby project that moves in bursts between my paying work and the research projects. It is not finished, and the most useful thing in this repo may be the sequence: what was tried, what the tests showed, and what got dropped. That record-keeping habit is the same one the evaluation projects run on, the game just came first.
